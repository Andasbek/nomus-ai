# Документация Nomus AI

Nomus AI — информационно-справочный сервис по трудовым правам иностранных
работников в Республике Казахстан. Отвечает только на основании действующих
НПА РК и подтверждает каждое утверждение ссылкой на конкретную статью.

> Это не юридическая консультация и не адвокатская деятельность.

## Что делает продукт

Мигрант описывает ситуацию своими словами — например, «не платят зарплату три
месяца, паспорт забрал работодатель». Сервис за несколько секунд:

1. **Находит норму** в законах РК гибридным поиском по 1817 статьям и пунктам.
2. **Проверяет каждую цитату**: если названной статьи нет в найденном тексте
   закона, ответ блокируется и не доходит до пользователя.
3. **Учитывает правовой режим**: гражданин ЕАЭС и гражданин Узбекистана
   получают разные ответы на один и тот же вопрос.
4. **Делает совет безопасным**: если документы не в порядке, первым шагом идёт
   НПО или консульство, а не госорганы, с явным предупреждением о рисках.
5. **Распознаёт принуждение**: изъятие паспорта, долговая кабала, запрет уходить
   с объекта — приоритетное сообщение с телефоном горячей линии 116 16.
6. **Формирует документ**: заявление в госинспекцию труда в формате `.docx`.
7. **Честно отказывается**, если нормы не нашлось, и даёт контакты живых
   юристов вместо правдоподобной выдумки.

## Два канала, одно ядро

Сервис доступен как Telegram-бот и как веб-сайт. Оба канала вызывают один и тот
же оркестратор, поэтому правила безопасности — валидация цитат, отказ от ответа,
red-flag, safety-режим — действуют одинаково и не могут разойтись между
каналами.

## Карта репозитория

```
nomus/
  pipeline/    RAG-ядро: rewriter, retriever, reranker, generator, validator
  bot/         Telegram-бот на aiogram 3
  api/         веб-API на FastAPI
  web/         статика лендинга (HTML/CSS/JS без сборщика)
  ingest/      парсер adilet.zan.kz и индексация в Qdrant
  db.py        SQLite: сессии и обезличенные метрики
  docgen.py    генерация заявления .docx
  schemas.py   модели данных: профиль, чанк, ответ LLM
  config.py    настройки из переменных окружения
eval/          тестовый датасет на 40 вопросов и прогон метрик
tests/         smoke-тесты и проверка живого API
docs/          эта документация
```

## Техническое задание

Исходные требования — в [TZ_Nomus_AI_MVP.md](../TZ_Nomus_AI_MVP.md). В
документации ниже требования упоминаются по идентификаторам вида `FR-21`
(функциональные), `SEC-02` (безопасность), `NFR-01` (нефункциональные),
`DR-03` (данные), чтобы можно было проследить, где именно каждое реализовано.

Одно отклонение от ТЗ зафиксировано сознательно: исходный документ выносил
веб-сайт за границы MVP («только Telegram»), но веб-канал был добавлен по
отдельному запросу. Подробности — в [Веб-API](api.md).
