# Корпус НПА

## Что входит в корпус

| Документ | Сокращение | Фрагментов | Роль |
|---|---|---|---|
| Трудовой кодекс РК | `ТК РК` | 1652 | основной источник трудовых прав |
| Закон «О миграции населения» | `Закон о миграции` | 605 | разрешения, регистрация, статус |
| КоАП РК (выборочно) | `КоАП РК` | 130 | ответственность работодателя |
| Договор о ЕАЭС (ст. 96–98) | `Договор о ЕАЭС` | 33 | режим для граждан ЕАЭС |

После удаления дубликатов — **1817 фрагментов**, что укладывается в целевой
диапазон ТЗ (1500–3000, требование DR-05).

Все редакции русскоязычные, источник — [adilet.zan.kz](https://adilet.zan.kz),
кроме Договора о ЕАЭС, текст которого входит в закон о ратификации на том же
портале.

### Почему КоАП взят выборочно

Полный кодекс даёт 4548 фрагментов, из которых к теме относятся десятки.
Остальное — космическая деятельность, ветеринария, журналистика — это шум,
который ухудшает поиск. В [sources.py](../nomus/ingest/sources.py) заданы
диапазоны статей:

| Диапазон | Содержание |
|---|---|
| 34 | ответственность иностранных граждан |
| 51 | административное выдворение |
| 86–98 | нарушения трудового законодательства |
| 516–521 | нарушения в области миграции |
| 693 | органы госконтроля в сфере труда |
| 916–917 | исполнение выдворения |

Диапазоны получены анализом заголовков статей всего кодекса, а не наугад.

## Структура фрагмента

```json
{
  "chunk_id": "тк_рк_st_113_p2",
  "text": "2. При выплате заработной платы работодатель обязан…",
  "parent_text": "Полный текст статьи 113 со всеми пунктами",
  "doc_title": "Трудовой кодекс Республики Казахстан",
  "doc_short": "ТК РК",
  "doc_id": "K1500000414",
  "chapter": "Глава 8. НОРМИРОВАНИЕ И ОПЛАТА ТРУДА",
  "article_num": "113",
  "article_title": "Порядок и сроки выплаты заработной платы",
  "point_num": "2",
  "revision_date": "2026-01-15",
  "status": "active",
  "url": "https://adilet.zan.kz/rus/docs/K1500000414#z113",
  "lang": "ru"
}
```

Поля `doc_short` и `article_num` — не справочная информация, а рабочие данные:
именно по ним валидатор сверяет цитаты из ответа модели, а фронтенд строит
ссылки на первоисточник.

## Чанкинг по структуре, а не по токенам

Корпус режется по границам документа: глава → статья → пункт. Нарезка по
фиксированному числу токенов разорвала бы норму посередине, и модель получила
бы половину условия без исключений из соседнего предложения.

**Ищется пункт, читается статья.** Поле `text` (пункт) векторизуется и участвует
в поиске — короткий фрагмент даёт точное попадание. В модель уходит
`parent_text` (статья целиком), потому что пункт вне статьи легко понять
неправильно: условия и исключения часто расположены рядом.

## Отсев утративших силу норм

Требование DR-02. Парсер помечает `status = "excluded"` статьи, начинающиеся с
«утратил силу», «утратила силу», «исключен». Такие фрагменты не индексируются —
совет по отменённой норме хуже отсутствия совета.

При индексации дополнительно ставится фильтр `status = active` на уровне
запроса к Qdrant, то есть защита двойная.

## Дедупликация

Страницы adilet содержат часть текста дважды (например, в оглавлении и в теле
документа). Без обработки Договор о ЕАЭС давал по два экземпляра каждого
пункта. Дубликаты удаляются по `chunk_id` — при последнем прогоне их было 603.

## Обновление корпуса

```bash
python -m nomus.ingest.download    # скачать исходники в data/raw/
python -m nomus.ingest             # распарсить и переиндексировать
```

Вторая команда полностью пересоздаёт коллекцию — воспроизводимость одной
командой требовалась ТЗ (DR-04). Промежуточный результат сохраняется в
`data/chunks/chunks.json`, его удобно просматривать при отладке парсера.

### Если скачивание не работает

Библиотека `httpx` может не принять цепочку сертификатов adilet. Обходной путь
без отключения проверки TLS — системное хранилище сертификатов через `curl`:

```bash
curl -sSL -A "Mozilla/5.0" -o data/raw/tk_rk.html https://adilet.zan.kz/rus/docs/K1500000414
```

Крайний вариант, предусмотренный ТЗ: сохранить страницы вручную из браузера в
`data/raw/` под именами из `sources.py`.

**Отключать проверку сертификатов не следует.** Корпус определяет содержание
правовых ответов, и подмена источника здесь — не теоретический риск.

## Добавление нового документа

1. Добавьте запись в `SOURCES` в [sources.py](../nomus/ingest/sources.py):
   заголовок, сокращение, идентификатор, дату редакции, базовый URL.
2. При необходимости укажите `article_ranges`, чтобы взять только нужные главы.
3. Скачайте файл в `data/raw/` и запустите `python -m nomus.ingest`.
4. Проверьте `data/chunks/chunks.json`: номера статей и заголовки должны быть
   распознаны, а не слиты в один блок.

Парсер рассчитан на разметку adilet. Документ с другой структурой может
потребовать правки регулярных выражений в
[parser.py](../nomus/ingest/parser.py) — там разбираются строки вида
`Статья 113. Название` и `2. Текст пункта`.

## Проверка перед демонстрацией

Поле `revision_date` заполняется вручную в `sources.py` и **не** извлекается со
страницы автоматически. Перед публичным показом сверьте даты редакций с
первоисточником: устаревшая отметка в метаданных вводит в заблуждение, даже
если текст свежий.
